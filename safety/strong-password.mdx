## What makes a password strong

A strong password is hard to guess and hard to reuse across services.

<Warning>Please use password that is easy to remember for you. If forgot your password, you can reset it using [Our Platform](https://prvtmarket.com/en/auth/reset-password)</Warning>

## Recommendations

- Use at least 12 characters (longer is better)
- Use a unique password for PRVT Market (do not reuse passwords)
- Prefer a passphrase made of multiple unrelated words
- Avoid personal information (name, birthday, company, phone number)

## Good examples

- A long passphrase with multiple words
- A password generated by a password manager

## Avoid these patterns

- Common passwords (for example: `password`, `123456`, `qwerty`)
- Small variations of a known password (for example: `Password1!`, `Password2!`)
- Reusing the same password on other sites

## Use a password manager

A password manager can generate and store unique passwords, so you do not need to memorize them.

## If you think your password was compromised

- Change your password immediately
- Do not reuse the old password anywhere else
- Contact support if you suspect unauthorized activity
